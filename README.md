# AudioFlux

**Минималистичный аудио-визуализатор для рабочего стола Wayland**

*Легковесный оверлей на C++, Qt/QML и LayerShellQt, отображающий бесконечно плавающие по экрану круги, пульсирующие в такт музыке.*

## О проекте

**AudioFlux** - это десктопный аудио-визуализатор для Linux-окружений на базе протокола Wayland (протестировано в композиторе **Niri** на CachyOS / Arch Linux). Приложение встраивается непосредственно в слой рабочего стола (Layer-Shell) в виде прозрачного неинтерактивного окна на фоне и отрисовывает плавно дрейфующие круги, размер и движение которых синхронизированы с битом и частотным спектром воспроизводимого аудио.

## Основные возможности

* **Живой фон рабочего стола (Layer-Shell):** Интеграция через `LayerShellQt` позволяет выводить графику поверх обоев и под окнами приложений без рамок, заголовков и перехвата фокуса ввода.
* **Спектральный анализ в реальном времени:** Захват системного аудиопотока через **PulseAudio** (`libpulse-simple`) и разложение сигнала на частотные полосы с помощью быстрого преобразования Фурье (**FFTW3**).
* **Реакция на бит и плавная анимация:** Выделение низких частот для пульсации и плавная физика бесконечного перемещения кругов по всему пространству монитора на базе **Qt Quick / QML**.
* **Интеграция с MPRIS:** Отслеживание состояния медиаплееров через D-Bus (MPRIS) для автоматического перехода в спящий режим при паузе и экономии ресурсов процессора и GPU.

## Технологический стек

* **Язык программирования:** C++
* **Графический интерфейс и рендеринг:** Qt 6 (Core, Gui, Quick, QML, DBus)
* **Интеграция с Wayland:** LayerShellQt
* **Обработка звука:** PulseAudio (`libpulse-simple`), FFTW3 (`fftw3`)
* **Система сборки:** CMake

## Зависимости

Для сборки и запуска в системе должны быть установлены следующие пакеты:

* Компилятор с поддержкой C++17 / C++20 (`gcc` или `clang`)
* `cmake`
* `qt6-base`, `qt6-declarative`
* `layer-shell-qt`
* `libpulse` (PulseAudio / PipeWire-Pulse)
* `fftw`

### Установка зависимостей в Arch Linux / CachyOS

```bash
sudo pacman -S cmake qt6-base qt6-declarative layer-shell-qt libpulse fftw
```

## Сборка и запуск

```bash
# Клонирование репозитория
git clone https://github.com/ProGiple/AudioFlux.git
cd AudioFlux

# Конфигурация и сборка проекта
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel

# Запуск визуализатора
./build/AudioFlux
```

### Автозапуск в Niri

Для автоматического запуска при старте сессии добавьте следующую строку в конфигурационный файл `~/.config/niri/config.kdl`:

```kdl
spawn-at-startup "/путь/к/AudioFlux/build/AudioFlux"
```
